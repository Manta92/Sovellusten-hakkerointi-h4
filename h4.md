Aloitin nimeämään funktioita uudelleen ja tutkimaan mitä tietoa ne saattaisivat sisältää, mutta se ei johtanut mihinkään. Luin uudestaan tehtävänantoa ja huomasin vinkeissä muistutuksen tiedoston purkamisesta. Tätähän en ollut vielä tehnyt, joten seuraava vaihe oli purkaa **packd**-tiedosto. Kalissa on UPX-ohjelma jo valmiina, joten sitä ei tarvinnut erikseen asentaa toisin kuin Debianissa. Tiedoston purkaminen tapahtui seuraavalla komennolla:

    $ upx -d packd

Tämä auttoi huomattavasti, sillä kun loin uuden projektin ja analysoin tiedoston, se antoi jo paljon selkeämmän käännöksen koodista josta selvisi salasana ja lippu. 

Ohjelma siis kysyy salasanaa, johon on koodissa määriteltyä oikea sana. 


    $ int main(void) // Ohjelman suoritus alkaa

    {
      int password; // Muuttuja joka palauttaa myöhemmän vaiheen strcmp()-funktion arvon
      char input [32]; // Luo 32-paikkaisen merkkitaulukon
  
      printf("What\'s the password?"); // Kysyy käyttäjältä salasanaa
      scanf(%31s, input); // Lukee käyttäjän antaman syötteen
      password = strcmp(input,"piilos-AnAnAs"); // Vertaa annettua merkkijonoa oikeaan salasanaan
      if (password == 0) { // Tarkistaa vastaavatko salasanat toisiaan
        printf("Yes! That\'s the password. FLAG{Tero-0e3bed0a89d8851da933c64fefad4ff2}");
    } // Tämä tulostetaan jos salasana oli oikein
      else { // Tämä tulostetaan jos salasana oli väärin
        printf("Sorry, no bonus.");
    }
      return 0; // Ohjelman suoritus päättyy
    }
